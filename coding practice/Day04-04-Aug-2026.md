TO PREVENT THIS VUNERIBILITY WE HAVE JUMP SERVER / BASTION HOST

We create a key inside this jump. and add this key to users servers who wish to connect

Vehicle entry in gated society is possible as there is a sticker(key) on the vehicle for identification.
Someone other than the real car owner can also enter.

We will generate a key at our end and put it in the Bastion host. So the Bastion host will no longer ask for a password and allow us to enter.

And there is a key already present in the bastion server that we have shared with the target server. 

Hence we will be able to connect. from our local to the target server via Bastion host. (using two different keys)

Private key → Public key

Find the public key on you local system > copy it and put it into the server

Now person having the key is able to login w/o any password
Anyone else from outside trying to login will not be able to login directly and will be asked to enter the password (that we enabled and setup earlier) 
Moreover due to security reason we will always avoid creating and logging in using a password.

FINAL SETUP
All the terget servers are setup with the public key of the Bastion host which allows Jump server to connect.

Hence the cyber security team just has to protect the bastion host (prevention any external IP from hitting)
So even if your private key gets compromised the attackers cannot direct get access to the target.

** cron job ** 

cron job is like an alarm with an action to be taken

Cron Job Syntax
Each cron job line has 6 fields:
* * * * * command_to_execute
| | | | |
| | | | └── Day of Week (0–7) (Sunday = 0 or 7)
| | | └──── Month (1–12)
| | └────── Day of Month (1–31)
| └──────── Hour (0–23)
└────────── Minute (0–59)

A cron job is a scheduled task in Unix/Linux systems that runs automatically at predefined times or intervals.
